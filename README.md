# CFA-44 Nosferatu

V0.5.3 changes the right wing strobe to light blue and retains its double flash; the left strobe remains red.

## Install

Download the V0.5.3 release ZIP, extract it, then run `install.ps1` with Nuclear Option closed. It installs the bundle and the required runtime assemblies, verifies their hashes, and backs up existing CFA-44 files.

## Verification

The packed right and left strobe checks passed. The live cockpit HUD fixture requires Unity batch mode, which was unavailable during this build, and an in-game visual check is still pending.
