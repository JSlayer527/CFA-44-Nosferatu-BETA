# CFA-44 Nosferatu V0.5.2

This repository provides the Nuclear Option CFA-44 Nosferatu V0.5.2 files.

## Download

Download the V0.5.2 ZIP from the [latest release](https://github.com/JSlayer527/CFA-44-Nosferatu-BETA/releases/latest).

## Install

1. Close Nuclear Option.
2. Extract the ZIP.
3. Copy the included `BepInEx` folder into the Nuclear Option installation folder and merge it with the existing `BepInEx` folder.
4. Start Nuclear Option.

The files should be placed like this:

```text
BepInEx/plugins/
├─ CFA44Animations/
└─ com.nikkorap.blueprinter/
   └─ addons/
      └─ CFA-44/
```

`CFA44Animations` contains the two animation libraries. `com.nikkorap.blueprinter/addons/CFA-44` contains the V0.5.2 Blueprinter aircraft package.
